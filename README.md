# Loan Approval Predictor (deployment trial)

A deployment trial of the [loan approval predictor](https://github.com/Mohamedatwa7/MachineLearning): a classifier that predicts whether a loan application is likely to be approved from gender, marital status, income, loan amount and credit history, served with Streamlit.

## Run it

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Stack

Python · scikit-learn · Streamlit
